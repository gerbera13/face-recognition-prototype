# Презентация: Система распознавания лиц для банка

---

## Слайд 1. Проблема

**Что мы решаем:**
- Очереди на идентификацию в отделениях
- Человеческий фактор при проверке документов
- Мошенничество с чужими паспортами
- Повышение уровня безопасности VIP-зон и хранилищ

**Цифры:**
- Среднее время опознания клиента операционистом: ~30 сек
- Система: **<1 сек**
- Точность нейросетевых решений: **99.8%** (при правильной реализации)

---

## Слайд 2. Как это работает (Pipeline)

```
Камера → Детекция лица → Извлечение признаков → Поиск по базе → Вердикт
                ↓                                   ↓
         Liveness-проверка                    СВОЙ / ЧУЖОЙ
```

**Технологии прототипа:**
- OpenCV (детекция + признаки)
- LBP + HOG + HSV (вектор признаков)
- Cosine similarity (сравнение 1:N)

## Слайд 5. Сценарии применения

1. **Вход в интернет-банк** — face ID вместо SMS-кода
2. **Идентификация в отделении** — клиент подошёл → система узнала → талон не нужен
3. **VIP-зона** — автоматический допуск по лицу
4. **Антифрод** — обнаружение известных мошенников в отделении
5. **Сейфовые ячейки** — доступ по биометрии

## Слайд 6. Риски и вопросы

- **152-ФЗ**: хранение биометрии требует согласия и защиты
- **ЕБС**: интеграция с Единой биометрической системой
- **Trust**: готовы ли клиенты сканировать лицо?
- **Точность**: ложные срабатывания — критичны для банка
